# A245211：69 因子情形的独立计算核验

**dot 提供的 69 因子模筛结果已独立复现：28,428 个完整位置分配经模 7、11、13 筛选后全部排除。** 在此基础上，加入模 3 的初筛可得到更短的证书：只需对 138 个完整位置分配再做模 7、11 检查，便能归零。

[独立检查脚本](audit_count69.py)只依赖 Python 标准库，[计算报告](audit_count69.json)记录精确计数、剩余位置和最终矛盾轨迹。**本目录当前提供可复算的有限算术证据，69 因子情形尚未通过 Lean 验证。** 现有 Lean 循环定理和投影引理可以连接到这份证书，但新的有限表仍需由内核验证。

## 目标与范围

沿用 A245211 的加权真因子和：

$$
a(n)=\sum_{\substack{d\mid n\\d<n}}d\,\tau(d).
$$

要排除的情形是：

```lean
∀ n : ℕ, Squarefree n → n.primeFactors.card = 69 →
  OeisA245211.a n ≠ n
```

**这里没有给整数 n 设置任何大小上界。** 有限枚举发生在数学归约后的因子位置空间，未对 n 做有界搜索。

这属于剩余分支 `OeisA245211.conjecture.R2.H3.R1.H2` 中的 69 因子情形。该分支要求素因子个数至少为 67、为奇数且不是正指数素数幂；67 是素数，68 是偶数，因此 69 是该条件下的第一个个数。它不同于已处理 `r < 65` 范围的旧 `R2.H2`。本目录不宣称解决整个剩余 H2、H3 或原猜想。

## 从固定点到有限位置分配

共享的[素数循环定理](../Cycle.lean)与[因子分配定理](../TokenAllocation.lean)表明，若存在符合条件的固定点，则存在长度 69 的素数循环：

$$
2p_{i+1}+1=d_i p_i,\qquad
\prod_{i=0}^{68}d_i=2^{69}+1,\qquad
p_i>2^{68},
$$

其中下标循环取模 69。精确因子分解是：

$$
2^{69}+1
=590295810358705651713
=3\cdot3\cdot139\cdot2796203\cdot168749965921.
$$

检查器使用确定性试除验证上述因子的素性，并核对整数乘积。最大因子的试除只需进行到其平方根。

把列表 `[3,3,139,2796203,168749965921]` 中每个素因子的每次出现看作一个有标签的 token，分配到 69 个乘子位置之一。**两个 3 保留为两个 token；多个 token 可以分配到同一位置。** 循环旋转允许把第一个 3 固定在位置 0，其他位置记作：

| Token | 所在位置 |
|---|---|
| 第一个 3 | 0 |
| 第二个 3 | a |
| 139 | b |
| 2796203 | c |
| 168749965921 | d |

其中 `a,b,c,d ∈ {0,…,68}`，因此归一化后的完整位置空间大小是：

$$
69^4=22,667,121.
$$

固定第一个有标签的 3 只用了循环旋转，没有对其余因子排序，也没有要求位置互异。

## 模筛为何可靠

### 闭合循环唯一确定起始剩余类

定义整数序列：

$$
S_0=0,\qquad S_{k+1}=d_kS_k+2^k.
$$

由循环递推逐步得到：

$$
2^k p_k+S_k
=\left(\prod_{j=0}^{k-1}d_j\right)p_0.
$$

取 `k=69`，使用 `p₆₉=p₀` 和乘积恒等式：

$$
2^{69}p_0+S_{69}=(2^{69}+1)p_0,
\qquad S_{69}=p_0.
$$

因此，任意给定位置分配都会强制一个起始剩余类 `p₀ mod q = S₆₉ mod q`。这是整数等式，不需要对某个未知系数求逆。

随后使用：

$$
p_{i+1}\equiv(d_i p_i-1)\,2^{-1}\pmod q.
$$

这里所有模数都为奇数，因此 2 的逆元存在，并等于 `(q+1)/2`。即使某个乘子模 q 为 0，这个正向递推仍然有效。

所有循环中的素数都大于 `2^68`，因此大于本次使用的 3、5、7、11、13。若模筛强制任何一个 `pᵢ ≡ 0 mod q`，就与素性矛盾。脚本实际检查的是每个余数与 q 互素。

[现有 Lean 检查器可靠性证明](../Checker.lean)连接了真实素数循环与此检查。[投影引理](../Projection.lean)证明，因子模 q 余 1 时可以从该模数的列表中删除，而不受其位置影响。

### 可以删除哪些因子

| 因子 | 模 3 | 模 5 | 模 7 | 模 11 | 模 13 |
|---|---:|---:|---:|---:|---:|
| 每一个 3 | 0 | 3 | 3 | 3 | 3 |
| 139 | 1 | 4 | 6 | 7 | 9 |
| 2796203 | 2 | 3 | 4 | 3 | 7 |
| 168749965921 | 1 | 1 | 5 | 9 | 4 |

模 3 可以暂时忽略 `b,d`；模 5 可以暂时忽略 `d`。换用后续模数时，需要重新遍历被忽略位置的全部可能值。

脚本对“被省略因子必须模 q 余 1”逐项断言；同时保持各阶段的位置分配一致，避免把不同模数下不相容的候选拼在一起。

## 路线一：复现 dot 的 28,428 → 0

dot 提供的方向采用模 5、7、11、13。独立重建后得到：

| 阶段 | 检查或保留的数量 |
|---|---:|
| 完整归一化位置空间 | 22,667,121 |
| 模 5 投影需要检查的 `(a,b,c)` | 328,509 |
| 通过模 5 的 `(a,b,c)` | 412 |
| 恢复每个 d 的 69 种位置 | **28,428** |
| 模 7 后 | **3,547** |
| 模 11 后 | **14** |
| 模 13 后 | **0** |

**28,428 是模 5 投影初筛后、恢复完整位置分配的数量。** 它并不是最原始的位置空间大小。报告中保留了模 11 后的全部 14 个位置分配，便于复算最后一轮。

## 路线二：更短的模 3、5、7、11 证书

先使用模 3，可以显著缩小后续证书。

### 第一步：模 3 只保留三对位置

完整检查 `69²=4,761` 对 `(a,c)`，仅剩：

```text
(a,c) = (0,1), (1,2), (68,1)
```

### 第二步：模 5 只保留两组三元组

对上述三对分别遍历 b，总计检查 `3×69=207` 组投影位置，仅剩：

```text
(a,b,c) = (1,4,2), (68,3,1)
```

### 第三步：恢复 d，再做模 7

遍历 d 的全部 69 个位置，一共有 `2×69=138` 个完整分配。模 7 后仅剩四个：

```text
(a,b,c,d) = (1,4,2,3)
           (1,4,2,68)
           (68,3,1,2)
           (68,3,1,67)
```

### 第四步：模 11 排除最后四个分配

以下下标从 0 开始；余数轨迹列出到第一次出现 0 为止：

| `(a,b,c,d)` | 强制的起始余数 | 第一次出现 0 的下标 | 模 11 余数轨迹 |
|---|---:|---:|---|
| (1,4,2,3) | 0 | 0 | 0 |
| (1,4,2,68) | 3 | 2 | 3 → 4 → 0 |
| (68,3,1,2) | 5 | 8 | 5 → 7 → 10 → 6 → 4 → 7 → 3 → 1 → 0 |
| (68,3,1,67) | 4 | 1 | 4 → 0 |

四种分配均与循环素数大于 11 矛盾。**这条路线不再需要模 13。**

在仓库根目录执行：

```bash

```

或者指定报告路径：

```bash
python3 A245211/count69/audit_count69.py /tmp/audit_count69.json
```

程序仅依赖 Python 标准库，默认更新同目录的 `audit_count69.json`。它验证：

- 完整因子分解和所有因子的确定性素性；
- dot 路线的 `412 → 28,428 → 3,547 → 14 → 0`；
- 短路线的 `3 → 2 → 138 → 4 → 0`；
- 最后四个分配的模 11 矛盾轨迹。

程序还使用第二种算法复核：对每个模数**枚举所有可能的起始余数**，沿递推检查互素性和最终闭合，而不使用 `S₆₉` 种子公式。该算法完整重算了短路线，并另行复核 dot 路线最后 14 个分配在模 11、13 下的结果。两种方法的结果完全一致。
