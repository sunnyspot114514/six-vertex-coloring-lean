# 六顶点图的二染色延拓引理

## 命题与范围

设 **G** 是一个至多有六个顶点、没有三角形的有限无向简单图。任意给它的边
染上 `false`、`true` 两种颜色，都能用这两种颜色给顶点染色，使得：

> 不存在一条边，它的两个端点都与这条边同色。

记边染色为 **c**、顶点染色为 **d**，条件写成：

$$
\forall\{x,y\}\in E(G),\qquad
\neg\bigl(d(x)=c(\{x,y\})\;\land\;d(y)=c(\{x,y\})\bigr).
$$

上游 Lean 陈述中的 `c x y = c y x` 保证边的颜色不依赖两个端点的顺序。
非边和对角线上的函数值不影响命题。

这是 **Erdős 第 151 题的无 K4 变体中，一个归约所使用的 H2 引理**。
证明这个引理，并不等于解决该变体或 Erdős 原问题。它的用途是：给图增加一个
新顶点时，把新顶点到 `x` 的边染成 `d(x)`，就不会出现经过新顶点的同色三角形。

## 图结构引理

**引理：至多六个顶点的无三角形图，删除至多一条边后，就会成为二分图。**

如果原图已经是二分图，不必删除任何边。否则，利用有限图“是二分图当且仅当
没有奇圈”的基本性质，图中存在奇圈。由于没有三角形，奇圈不能长为三；由于
顶点数至多为六，奇圈也不可能长为七或更大。因此，图中存在一个五圈 **C**。

这个五圈不能有弦：五圈的任意一条弦，都会与两端之间较短的两条圈边构成
三角形。圈外至多还有一个顶点 **v**。如果它存在，它在五圈上的邻居必须构成
独立集，否则 v 与两个相邻的邻居就会构成三角形。五圈的独立集大小至多为二，
所以 v 至多连接五圈上的两个顶点。

于是只需讨论两种情况：

1. **没有圈外顶点，或者圈外顶点至多有一个邻居。** 任意删除五圈的一条边。
   剩下的是一条路径，外加一个可能存在的孤立点或叶子，因而是森林，也是二分图。
2. **圈外顶点连接五圈上两个顶点 a、b。** a、b 不相邻，它们沿五圈的两条路径
   长度分别为二和三；经过 v 的路径 `a–v–b` 长度也为二。删除长度为三的路径上的
   一条边。剩下的两条长度为二的路径构成四圈，被打断的第三条路径只在四圈上
   附加一些路径片段。剩余图唯一的圈是偶圈，因此是二分图。

五圈没有弦，也没有其他未讨论的顶点，所以这些情况已经穷尽。结构引理得证。

## 构造所需的顶点颜色

如果 G 是二分图，直接使用二分图的正常顶点二染色：每条边两端异色，因而
无论边如何染色，都不会出现“两端与该边全部同色”。

否则，按照结构引理选出一条边 **e = {u, v}**，对 **G − e** 进行正常顶点
二染色。除了 e，其余边两端全部异色。e 的两个端点同色：e 原本属于那个五圈，
删除它以后，圈上的另外四条边仍构成连接 u、v 的偶数长度路径。

如果 u、v 的共同颜色与 c(e) 不同，保留当前染色。如果相同，就将**所有顶点**
的 `false`、`true` 颜色整体互换。这样，e 两端的共同颜色变成了与 c(e) 相反的
颜色；其余边两端仍然异色。因此，每条边都满足要求，命题得证。

这个论证还给出一个更一般的结论：**任何删除至多一条边就能成为二分图的图，
都具有同样的边染色延拓性质。** “至多六个顶点”和“无三角形”这两个条件，只在
证明前面的图结构引理时使用。

## 独立穷举核验

[`check_exhaustive.py`](../scripts/check_exhaustive.py) 是独立编写、仅使用 Python
标准库的构造与核验程序。使用 Python 3.10 或更高版本运行：

```bash
python scripts/check_exhaustive.py
```

程序枚举顶点集合 `{0, 1, 2, 3, 4, 5}` 上所有带标号的简单图。六个顶点之间
有十五条可能的边，所以总共有 `2^15 = 32,768` 个图。程序直接检查三角形，
并通过图遍历判断二分性。对每个非二分的无三角形图，它找到一个五圈，严格按照
上述结构证明的两种情况选择要删除的边，再对**所有可能的现有边二染色**检查
所得顶点染色是否满足条件。

| 项目 | 数量 |
| --- | ---: |
| 六顶点带标号简单图总数 | 32,768 |
| 无三角形图 | 5,789 |
| 二分图 | 5,177 |
| 非二分的无三角形图 | 612 |
| 已核验的“图／边染色”组合 | 294,987 |
| 需要整体互换顶点颜色的情况 | 24,192 |

不足六个顶点的图，可以添加孤立顶点补成六个顶点，再把所得染色限制回原图。
程序输出确定性的 JSON，其中还包含核验过的“图／边染色”组合数量；任何构造
或染色不符合要求，程序都会报错退出。

这份 Python 穷举是额外的可复现检查，**不等于 Lean 内核证明**。上面的数学
证明也不依赖这段程序的运行结果。
